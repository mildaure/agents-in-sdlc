通过真实场景、完整应用程序和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。你将以迭代方式规划更改、编写代码、测试行为、审查拉取请求并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为棋盘游戏众筹，并以开发人员为主题。团队的待办事项已经作为 GitHub 议题创建，可供你选择。任务包括筛选和分页等功能，以及无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合自己的开发环境。每个工作坊都有自己的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验计划和自动驾驶模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

运行并行智能体会话、切换会话模式、协作处理 Canvas，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、引导其工作、监视进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
