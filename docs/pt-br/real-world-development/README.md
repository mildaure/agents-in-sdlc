Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora na Tailspin Toys, uma empresa fictícia de financiamento coletivo para jogos de tabuleiro com tema de programação. O backlog da equipe já está registrado como issues do GitHub, prontos para você escolher. Ele inclui tarefas de desenvolvimento, como filtragem e paginação, e melhorias de qualidade, como acessibilidade e padrões de programação.

## Escolher seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente mais adequado à maneira como deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em canvas e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise as pull requests criadas por ele.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
